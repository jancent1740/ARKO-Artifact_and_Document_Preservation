## 🎯 Quick Reference Cards

### Development Quick Reference
```bash
npm install      # Install dependencies (first time)
npm run dev      # Start development server
npm run build    # Build for production
npm run preview  # Preview production build
npm run lint     # Check code quality
```

### File Locations Quick Reference
```
Config:        vite.config.ts, tsconfig.json
Entry:         src/main.tsx, App.tsx
Components:    /components/*
Pages:         /pages/*
Styles:        /styles/globals.css
Docs:          /*.md files
```

### Common Tasks Quick Reference
```
Add page:      Create in /pages, add route in App.tsx
Add component: Create in /components, import where needed
Fix styles:    Edit /styles/globals.css
Debug:         Check browser console (F12)
Deploy:        Run npm run build, upload /dist
```
